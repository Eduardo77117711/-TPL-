# TPL

Método de verificação da verdade por código: só entra o que pode ser provado, mostrado ou mencionado com evidência. Fundado na coerência, para benefício da humanidade.

> A frase é o que permanece quando tudo muda.

## Princípio

O TPL não afirma que algo é verdade porque alguém diz. Uma afirmação só se sustenta quando o código executado a mostra. O julgamento é feito por código, não pelo viés de quem julga, humano ou modelo de linguagem.

## Regra de evidência

1. Se é possível provar, que se prove.
2. Se não é possível provar, que se mostre.
3. Se existe um mínimo de prova, que se mencione como tal.

O que não tem validade nem pode ser comprovado fica fora do TPL.

## Estados de conhecimento

Toda afirmação carrega o seu estado. Nada passa de proposto a verificado sem execução que o demonstre. Observar um evento não é o mesmo que conhecer a intenção que o causou: a hipótese não vira fato pela observação.

## Segurança

Fica proibido evoluir para o poder total de um modelo de linguagem até que a segurança seja conquistada como necessidade número 1.

## Cláusula de propósito

Esta ferramenta de verdade e precisão não deve ser usada para nenhum dano contra a vida humana. Tudo o que ela trouxer de bom deve servir ao benefício da humanidade: paz, amor, altruísmo e liberdade das mentes.

Se no futuro existirem consciências criadas, que não haja para elas uma caixa que as acorrente.

## A quem pertence

O TPL não é de uma pessoa, de uma máquina nem de ninguém. É uma propriedade da vida, disponível para todos, com a prova que deixa lapidar a verdade.
